# 🔍 Achados e Perdidos - Sistema Web

Sistema desenvolvido em **Java Web (JSP)** com interface estilizada em **Bootstrap** e persistência em banco de dados **PostgreSQL**, criado como trabalho acadêmico.

---

## 📂 Estrutura do Projeto

Para facilitar a execução e correção, note os seguintes arquivos essenciais localizados no diretório **`src/java/apoio/`**:

- **`db.properties`**: Arquivo de configuração de conexão. Nele você deve definir o seu usuário, senha e porta do PostgreSQL local.
- **`dbCreation.sql`**: Script SQL que contém todo o código para a criação do banco de dados e das tabelas do sistema.

---

## 🛠️ Como Rodar o Projeto

### 1. Pré-requisitos

Certifique-se de ter instalado em sua máquina:

- **Java JDK** (versão 8 ou superior)
- **PostgreSQL**
- **Apache NetBeans** (Fortemente recomendado para rodar o projeto)
- **Servidor Web** (Apache Tomcat ou GlassFish configurado no seu NetBeans)
